Overview:
Expense Tracker is a Java-based Android app that lets users log in, record their daily expenses, organize them into categories, and view their spending through visual charts and reports. All data is stored locally on-device using Room Database.

Features:
Login / Authentication — user sign-in to access their expense data
Add, Edit, Delete Expenses — full CRUD support for managing expense entries
Categories — organize expenses by category
Charts & Reports — visual summary of spending patterns
Local Storage — all data persisted offline using Room Database (no external backend required)


Tech Stack:
Language: Java
Database: Room Database (local/offline storage)
Platform: Android


Installation
Clone the repository:
bash   git clone https://github.com/khushi22-coder/ExpenseTracker-App


Open the project in Android Studio.
Let Gradle sync and download the required dependencies.
Build and run the app on an emulator or physical Android device.


Usage
Launch the app and log in.
Add a new expense with an amount, category, and description.
Edit or delete existing expenses as needed.
View spending charts and reports to track your expenses over time.
